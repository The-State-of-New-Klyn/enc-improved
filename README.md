# 🔐 Encryptor Improved

> **Encryptor Improved** — проект по созданию усовершенствованной, безопасной и расширяемой системы шифрования данных, развивающий идеи устаревшего криптографического скрипта *Miles Paradoxum AES-256-CBC*.

⚠️ **ВНИМАНИЕ:** Данное программное обеспечение постоянно обновляется и не является конечным продуктом. Код может работать нестабильно, содержать изъяны/уязвимости/ошибки и другие проблемные мелочи. Поскольку он открыт для всех, не рекомендуется использовать его сборки для защиты критически важных или конфиденциальных данных. Однако вы по прежнему можете использовать его в образовательных, ознакомительных целях или для усовершенствования в будущем.

## 📔 Использование

Если вы желаете использовать данный проект по его прямому назначению, рекомендуем обратиться к этому абзацу.
Здесь перечислены файлы и за что они отвечают.

* *code.js*: Основная библиотека CryptoJS
* *index.html*: Основной файл, исполняющий только шифрование AES-256 в режиме CBC без стеганографии
* *lsb.html*: Исполняющий файл для шифрования AES-256 в режиме CBC и с возможностью стеганографии (изображений) по методу LSB
* *meta.html*: Аналог lsb.html, но с методом стеганографии по текстовому чанку (по факту метаданным)
* *lsb.js* и *meta.js*: Самописные библиотеки (scripts) для работы соответствующий .html файлов (в т.ч. перевод в Z85 (упр. Base85) и инициализация)
* *stego_lsb.js* и *stego_meta.js*: Дополнительные библиотеки (scripts), выполняющие функции конкретно стеганографии (исключительно стеганография)
* *README.md*: Служебный файл для текста на GitHub
* *LICENSE*: Текст лицензии по которой распространяется скрипт (MIT (c) 2026 The State of New Klyn)  
* *LICENSE_LIB*: Текст лицензии по которой распространяется библиотека CryptoJS (MIT (c) 2009-2013 Jeff Mott и MIT (c) 2013-2016 Evan Vosberg)

## 🎯 Цели проекта

Главная задача репозитория — провести глубокий рефакторинг исторического скрипта, исправить архитектурные уязвимости и создать мощную утилиту для нужд граждан цифрового государства New Klyn:

*   **🛡️ Повышение безопасности:** Переход на современные, криптографически стойкие стандарты шифрования (AES-256-GCM / CBC с правильной генерацией криптографической соли и векторов инициализации IV).
*   **📂 Универсальность:** Разработка модулей для надежного шифрования и дешифрования не только простого текста, но и файлов любых форматов прямо в браузере.
*   **🧩 Расширяемость:** Архитектура проекта создается с расчетом на легкое подключение других современных алгоритмов шифрования помимо AES (например, ChaCha20-Poly1305).
*   **💻 Чистый веб-интерфейс:** Создание автономного, легковесного HTML/JS приложения, работающего полностью на стороне клиента (без отправки данных на сервер).
